Configuración NeoVim en LazyVim

- Configuracion necesita nvim 0.12 o superior

## Plugins

Gestionados con [lazy.nvim](https://github.com/folke/lazy.nvim):

- `folke/lazy.nvim` — gestor de plugins
- `greggh/claude-code.nvim` — integración con Claude Code
- `rstacruz/vim-closer` — autocierre de pares (paréntesis, comillas, etc.)
- `github/copilot.vim` — GitHub Copilot
- `tpope/vim-fugitive` — comandos de Git
- `ThePrimeagen/harpoon` (rama `harpoon2`) — navegación rápida entre archivos
- `lukas-reineke/indent-blankline.nvim` — guías de indentación
- `neovim/nvim-lspconfig` — configuración de servidores LSP
  - `stevearc/conform.nvim` — formateo de código
  - `williamboman/mason.nvim` — instalador de LSP servers/herramientas
  - `williamboman/mason-lspconfig.nvim` — puente entre mason y lspconfig
  - `hrsh7th/nvim-cmp` — autocompletado
  - `hrsh7th/cmp-nvim-lsp`, `hrsh7th/cmp-buffer`, `hrsh7th/cmp-path`, `hrsh7th/cmp-cmdline` — fuentes de autocompletado
  - `L3MON4D3/LuaSnip` y `saadparwaiz1/cmp_luasnip` — snippets
  - `j-hui/fidget.nvim` — indicador de progreso del LSP
- `xero/miasma.nvim` — colorscheme
- `nvim-telescope/telescope.nvim` — buscador difuso de archivos/texto
- `nvim-treesitter/nvim-treesitter` — resaltado de sintaxis basado en treesitter
- `nvim-lua/plenary.nvim` — librería de utilidades (dependencia de varios plugins)
